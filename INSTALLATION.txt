================================================================================
QUICK START (5 MINUTES)
================================================================================

1. VERIFY PREREQUISITES
   - Node.js 18+: https://nodejs.org (LTS)
   - npm 9+: Comes with Node.js

   Check:
   $ node --version    (Should be v18+)
   $ npm --version     (Should be 9+)

2. GET API KEYS (FREE TIER AVAILABLE)

   A. Firecrawl (web crawling)
      → https://firecrawl.dev/signup
      → Get free API key in dashboard
      → Add to .env as: FIRECRAWL_API_KEY=...

   B. Tavily (competitor search)
      → https://tavily.com/signup
      → Get free API key in dashboard
      → Add to .env as: TAVILY_API_KEY=...

   C. OpenAI or Claude (LLM analysis)

      Option 1: OpenAI (recommended for beginners)
      → https://platform.openai.com/api-keys
      → Get free trial: $5 credit
      → Add to .env as: OPENAI_API_KEY=sk_...

      Option 2: Claude (alternative)
      → https://console.anthropic.com/api-keys
      → Get API key
      → Add to .env as: CLAUDE_API_KEY=sk-ant-...

3. INSTALL & CONFIGURE

   # Copy example config
   $ cp .env.example .env

   # Edit .env with your API keys
   $ nano .env    (or use your editor)

   # Install dependencies
   $ npm install

4. VALIDATE SETUP

   $ bash scripts/validate.sh

   This will check:
   - Node.js installation
   - All API keys configured
   - Build successful
   - Ready to analyze

5. RUN YOUR FIRST ANALYSIS

   $ npm run analyze -- --url=https://slack.com

   Output will be in ./output/ directory:
   - YYYY-MM-DD_company-name.json (structured data)
   - YYYY-MM-DD_company-name.md (readable report)

That's it! You've completed setup.

6. Generate competitive analysis

OUTPUT:

- Strengths/weaknesses comparison

CONFIGURATION
================================================================================

Environment variables (.env):

Required:
  LLM_PROVIDER          "openai" or "claude"
  OPENAI_API_KEY        sk_... (if using OpenAI)
  CLAUDE_API_KEY        sk-ant-... (if using Claude)
  FIRECRAWL_API_KEY     Your Firecrawl key
  TAVILY_API_KEY        Your Tavily key

Optional:
  OPENAI_MODEL          Default: gpt-4o
  CLAUDE_MODEL          Default: claude-3-5-sonnet-20241022
  LOG_LEVEL             debug|info|warn|error (default: info)
  OUTPUT_DIR            Default: ./output
